# Memos One — UI 改版方案 v1

> 基于 **UI UX Pro Max** skill 检索（style / color / typography / ux / flutter）  
> 并结合产品约束：Offline First · 桌面优先 · Memos 生态辨识 · 用户已定白底 + 手绘鸟 Logo  
> 日期：2026-08-04  
> 状态：方案稿（待确认后按 Phase 实施）

---

## 1. 产品与人群（设计前提）

| 维度 | 结论 |
|------|------|
| 产品类型 | 生产力 / 笔记 / 知识库客户端（非营销落地页） |
| 主场景 | 快速浏览 → 阅读预览 → 编辑保存；云端同步在后台 |
| 平台 | macOS / Windows 桌面优先，Android 后置；Flutter |
| 品牌锚点 | 官方 Memos 小鸟、极简笔记感、「本地先写、联网再同步」 |
| 用户已拍板 | **纯白底**、应用内 **手绘鸟 Logo**（需够大、清晰） |

Skill 默认会偏向「SaaS 落地页 / 文档站」结构；本方案**只取方法与原则**，版式按 **桌面三栏 + 信息流** 重写。

## 2. Skill 推荐摘要（经品牌校准）

### 2.1 风格方向（Style）

| Skill 候选 | 采纳 | 用法 |
|------------|------|------|
| **E-Ink / Paper** | ✅ 主风格 | 阅读/笔记感：高对比墨色、少装饰、弱动效 |
| **Minimal & Direct** | ✅ | 一屏一个主操作；少 chrome |
| **Swiss Modernism 2.0** | ✅ 布局 | 8px 网格、清晰层级、单强调色 |
| Exaggerated Minimalism | ⚠ 仅 UI chrome | **不**在正文区用超大标题；留给空状态/引导页 |

**一句话定位：**  
> **「白纸笔记本 + 一条海绿色」** — 安静、可读、像工具不像营销站。

### 2.2 调性刻度（Design Dials）

| Dial | 取值 | 含义 |
|------|------|------|
| Variance | 3/10 | 居中、克制，不走 Bento/Brutal 乱序 |
| Motion | 2/10 | 150–250ms 微交互；无大滚动编排 |
| Density | 7/10 | 桌面列表略密（效率），阅读区留白 |

### 2.3 反模式（必须避免）

- AI 紫粉渐变、霓虹、重玻璃拟态  
- 复杂多层阴影 / 3D  
- Emoji 当系统图标  
- 仅靠颜色传达状态（同步失败必须有文案/图标）  
- 设置页长列表淹没（已修方向：摘要卡片 + 详情抽屉）  
- 信息流与笔记区混用「编辑/预览双开关」干扰（已改为保存回预览）

## 3. 设计令牌（Token）— 校准版

> Skill 泛用蓝灰 SaaS 色**不直接照搬**；保留用户已用的海绿与纯白。

### 3.1 颜色

| Token | Hex | 用途 |
|-------|-----|------|
| `--bg` / paper | `#FFFFFF` | 全局底、侧栏、内容区 |
| `--surface` | `#FFFFFF` | 卡片（白底 + 边框分层，不用米色） |
| `--surface-muted` | `#FAFAFA` | 悬停、次级条、输入浅底 |
| `--ink` | `#1C1B19` | 主文字 |
| `--ink-muted` | `#6E6860` | 次要文字、时间戳 |
| `--line` | `#E8E8E6` | 分割线、卡片描边 |
| `--accent` | `#2F6F5E` | 主操作、选中、链接 |
| `--accent-soft` | `#D7E8E1` | 选中底、chip、Logo 点缀 |
| `--danger` | `#B42318` | 删除、同步失败 |
| `--warning` | `#B54708` | 待同步（非错误） |
| `--focus-ring` | accent 40% | 键盘焦点 2–3px |

**对比：** 正文 ink on white ≥ 4.5:1；次要文字用 muted + 足够字号，避免灰上灰。

### 3.2 字体（Flutter 桌面）

| 角色 | 建议 | 说明 |
|------|------|------|
| UI 字 | 系统优先：`SF Pro` / `Segoe UI` / 中文回落 `PingFang SC` / `Microsoft YaHei` | 不强制 Google Fonts，冷启动更快 |
| 阅读正文 | 同上，字号 **15–16**，行高 **1.55–1.65** | Markdown 预览 |
| 编辑等宽 | `Menlo` / `Cascadia Mono` / `Consolas` | 编辑态 |
| 层级 | title 17–20 w600–700；body 14–16 w400–500；label 12–13 w500 | 全应用统一 |

Skill 的 Lora/Raleway 更偏 wellness 落地页，**不引入**，避免与「工具」气质冲突。

### 3.3 间距与圆角（8pt 节奏）

| Token | 值 |
|-------|-----|
| space-1…6 | 4 / 8 / 12 / 16 / 24 / 32 |
| radius-sm / md / lg | 8 / 12 / 16 |
| 列表行内边距 | 12–14 水平 / 10–12 垂直 |
| 内容最大阅读宽 | 笔记正文 **720–760px** 居中（宽屏） |

### 3.4 动效

- 时长 **150–250ms**，ease-out 进入  
- 列表选中：背景色交叉淡入，无位移抖动  
- 尊重 `reduce motion`：直接切换  
- **禁止** 大范围 page flip、视差

### 3.5 图标

- 统一 **Outline 线性**（Flutter Material Symbols / 自定义 stroke 一致）  
- 导航：笔记 / 信息流 / 公开 / 日历 / 设置 / 新建（**无多工作区轨**）  
- 状态：云朵 done / sync / offline / error（**图标 + 短文案**）

## 4. 信息架构与桌面布局

### 4.1 总壳（Shell）— Studio Pop · 单云端

```
┌────┬──────────────────────────────────────────────────────┐
│ 84 │  圆角主面板（白底 + 粗描边 + 偏移阴影）                 │
│ 图标│  TopBar：模式标题 · 云端 chip · 同步胶囊 · 新建        │
│ 导航│────────────────────────────────────────────────────│
│ +  │  依模式：笔记列表|详情 | 信息流 | Explore | 日历        │
│Logo│  画布背景：薰衣草雾 #F6F2FF                           │
└────┴──────────────────────────────────────────────────────┘
```

| 区域 | 规则 |
|------|------|
| 左轨 | 宽 **84**；Logo **≥56**；项 = 图标 + Tooltip；选中 = 玫瑰浅底 + 描边 |
| 云端 | **单一连接**；地址显示在 TopBar chip；管理在设置「云端」 |
| TopBar | 高度 ~64；左 EN+中 模式标题；右同步 + 新建 |
| 主内容 | 白面板 28px 圆角；**2px 墨线 + 硬阴影**，非传统笔记灰白 |

### 4.2 四模式职责

| 模式 | 布局 | 主任务 |
|------|------|--------|
| **笔记** | 列表 300–320 + 详情铺满 | 管理、筛选、精读/编辑 |
| **信息流** | 全宽卡片流；点进全文 | 快速扫、再深入 |
| **Explore** | 同信息流结构 | 公开笔记浏览 + 外链 |
| **日历** | 热力 + 可选列表 | 按日跳转笔记 |

### 4.3 导航 UX（Skill §9 对齐）

- 当前模式：**色 + 底** 双重高亮（非仅颜色）  
- 返回可预期：信息流/Explore 全文 → 返回列表，清空选中  
- 设置为**二级全页**（侧栏导航分区），不在主壳塞满表单

## 5. 关键页面改版规格

### 5.1 信息流

- 卡片：白底 + `line` 边框 + radius 14；**无重阴影**  
- 摘要 **3 行 / ~160 字**；底栏「查看全文 →」  
- 元信息一行：时间 · 标签 · 同步小标记  
- 点击 = 路由到全宽详情（预览默认）  

### 5.2 笔记列表

- **状态筛选**一行：全部 / 置顶 / 公开 / 归档（Chip）  
- **标签筛选**独立控件：入口按钮 + 可搜索底部 sheet（已实现方向）  
- 选中行：`accent-soft` 底 + 左侧 3px accent 条（强化位置感）  
- 虚拟列表：>80 条考虑 `ListView.builder` 已有则保持  

### 5.3 详情 / 编辑

| 状态 | UI |
|------|-----|
| 预览 | Markdown；主按钮 **编辑**；可选双击进入 |
| 编辑 | 等宽编辑区；主按钮 **保存**（回预览）+ 次要 **取消** |
| 公开 | 顶栏固定 **公开链接** 条：`{origin}/memos/{uid}` |
| 工具 | 可见性 / 置顶 / 归档 / 历史 / 删除 — 次要 icon，危险操作右置 |

### 5.4 Explore

- 与信息流**同组件语言**（卡片规格、字号、间距）  
- 列表不塞满全文；详情头含外链  

### 5.5 日历

- 当天：**2px accent 描边 + 字重 800**  
- 有笔记：填充阶梯用 accent 透明度，**有笔记的格子文字保持可读**  
- 选中日：筛选 chip 必须高对比（已修）  

### 5.6 设置（结构重构）

**分区侧栏 + 单页内容**（已部分落地），统一视觉：

1. **外观** — 主题、强调色（色点 36px）  
2. **笔记** — 默认可见性、双击编辑  
3. **同步** — **健康摘要卡**（状态 / 错误一句 / 立即同步 / 全部重试 / 清空 / 详情 sheet）  
4. **工作区** — 当前连接、危险删除  
5. **账户**（登录后）— 资料卡、重登、Token 说明外链  
6. **关于** — 大 Logo + 版本 + 快捷键  

**禁止** 在设置主滚动区展开上百条 dead task。

### 5.7 同步状态（全局）

顶部「胶囊」语义：

| 状态 | 文案示例 | 色 |
|------|----------|----|
| idle + 0 pending | 已同步 | accent |
| pending | N 条待同步 | warning 系 |
| syncing | 同步中… | accent + 旋转 |
| offline | 离线可编辑 | muted |
| auth | 需要登录 | danger |
| error / dead | 同步失败 | danger |

点击胶囊 → 打开同步面板（设置·同步 或 小型 popover）。

### 5.8 空状态

- 一插画位（手绘鸟小尺寸或简单线框）  
- 一句说明 + **一个主 CTA**（新建 / 连接服务器 / 登录）  
- 无装饰堆砌  

### 5.9 引导 / 登录

- 大 Logo（≥96）  
- 单列 max-width ~420  
- 错误：**条幅** 说明原因 + 可重试；失败不离开引导（已有原则）

## 7. 响应式

| 宽度 | 行为 |
|------|------|
| ≥1100 | 左轨 + 可选工作区 + 列表 + 详情 |
| 900–1099 | 左轨 + 列表 + 详情（工作区折叠） |
| <900 | 左轨收窄或底部/抽屉；笔记列表→详情全屏返回 |
| 触控 | 目标 ≥44；Chip 间距 ≥8 |

## 8. 无障碍与质量门禁（交付前）

- [ ] 正文对比 ≥ 4.5:1；失败/成功非仅靠色  
- [ ] 图标按钮有 `tooltip` / semantics label  
- [ ] 焦点环可见（键盘）  
- [ ] 列表 50+ 保持流畅（虚拟滚动）  
- [ ] `reduce motion` 关闭非必要动画  
- [ ] 公开链接格式 `/memos/{id}`  
- [ ] 同步失败可重试且不淹没设置

## 9. 实施阶段（建议）

### Phase A — 令牌与壳（0.5–1d）

1. `AppTheme` 语义化（warning / surfaceMuted / focus）  
2. TopBar + 左轨间距/选中态统一  
3. Logo 尺寸与白底定稿  

### Phase B — 内容组件（1–2d）

1. 抽取 `MemoSnippetCard`（Feed + Explore）  
2. 列表选中指示条 + 筛选条视觉统一  
3. 详情工具条层级（主按钮 / 次要 / 危险）  

### Phase C — 设置与同步表达（1d）

1. 同步健康卡交互打磨（popover / 深链设置）  
2. 设置分区视觉与空/错状态  
3. dead task 仅摘要（已具备逻辑）  

### Phase D — 抛光（0.5–1d）

1. 空状态、加载 skeleton  
2. 微动效 + reduced motion  
3. 宽屏阅读宽度限制  
4. 自检 checklist

## 10. 成功标准（可感知）

用户应感到：

1. **更像专业笔记客户端**，而非未完成 Demo  
2. **扫信息流很快**，点进全文不迷路  
3. **同步状态 3 秒内看懂**，失败能处理  
4. **设置清爽**，再也不被失败列表淹没  
5. **一眼认出 Memos**（鸟 + 极简 + 绿点缀），同时是「One」客户端
